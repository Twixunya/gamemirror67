GameMirror — Дневник влияния игр на самооценку и эмоциональное состояние
GameMirror — это интерактивный сервис и дневник трекинга игрового состояния, который помогает геймерам отслеживать влияние побед, поражений и продолжительности игровых сессий на их самооценку, эмоциональный фон и уровень стресса.

🚀 Основные возможности проекта
15-секундный чек-ин: Быстрый замер самооценки и настроения (по шкале 1–10) до и сразу после завершения игровой сессии.

Защита от тильта и триггеров: Определение жанров и игровых сценариев, провоцирующих тильт или эмоциональное выгорание.

Интерактивный симулятор: Оценка динамики состояния с наглядным построением тренд-линий (SVG-график) и получением быстрых психо-рекомендаций.

Глубокая аналитика: Наглядная корреляция факторов «часы в игре ↔ самооценка» и динамика показателей за 30 дней.

Конфиденциальность: Полное шифрование пользовательских данных без публичных рейтингов.

🛠 Технический стек (Full-Stack Architecture)
Frontend
Фреймворк/Библиотеки: React + TypeScript (Vite), HTML5, Tailwind CSS

Компоненты & Визуализация: Recharts (для детальных графиков аналитики), SVG Trend Charts, FontAwesome Icons

Интерактивность: JavaScript (DOM, клиентская валидация, интерактивные слайдеры, виджеты и уведомления)

Backend & База данных
Серверная часть: Node.js + Express (REST API)

База данных & ORM: PostgreSQL + Prisma ORM

Аутентификация & Безопасность: JWT (JSON Web Tokens), bcrypt (хеширование паролей), httpOnly cookies, Helmet, CORS, Rate Limiting, Zod (валидация схем данных)

Инфраструктура & Деплой
Контейнеризация: Docker, Nginx

Хостинг: Vercel / Railway

📡 Основные REST API Эндпоинты
POST /auth/register — Регистрация нового пользователя

POST /auth/login — Вход и выдача JWT-токена

GET/POST/PUT/DELETE /entries — Управление записями игрового дневника (CRUD)

GET/POST /games — Работа с каталогом игр и автодополнением (интеграция с RAWG API)

GET /stats/mood?range=30d — Выгрузка агрегированных данных настроения для графиков

GET /stats/self-esteem — Выгрузка показателей динамики самооценки

GET /entries/export — Экспорт данных дневника в форматах JSON / CSV

🔧 Запуск и развертывание
1. Быстрый просмотр лендинга (Static Preview)
Откройте файл index.html (вместе с script.js и style.css) или монолитный файл GameMirror_Landing_Page 2.html непосредственно в любом современном браузере.

2. Запуск Full-Stack приложения (Разработка)
Клонирование и зависимости:

Bash
npm install
Настройка окружения (.env):
Укажите параметры подключения к PostgreSQL (DATABASE_URL) и секретный ключ JWT_SECRET.

Миграция БД:

Bash
npx prisma migrate dev
Запуск серверов разработки:

Bash
# Backend
npm run dev:server
# Frontend (Vite)
npm run dev:client
